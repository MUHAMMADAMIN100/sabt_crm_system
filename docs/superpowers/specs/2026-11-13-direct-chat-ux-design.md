# «Директ»: удобство чата (13.11.2026)

Решения владельца — по вопросам 13.11.2026. ИИ в чат не добавляем.

## Что делаем

**Поле ответа и сообщения**
- Шаблоны быстрых ответов: кнопка ⚡ и «/» в начале поля. Общие (ведёт руководство) + личные (у каждого свои). Подстановки `{имя}` (клиент), `{менеджер}` (я).
- Ответ на конкретное сообщение (цитата): уходит в Instagram с `reply_to.mid`; если Instagram отказал параметру — уходит без него, цитата видна в CRM. Цитаты клиента (reply_to) тоже показываем; клик по цитате — к сообщению.
- Реакция ❤️ на сообщение (`sender_action: react/unreact`), двойной клик — ❤️. Меню сообщения: ответить, ❤️, копировать.
- Эмодзи, Ctrl+V скриншота, перетаскивание файлов, до 10 файлов за раз, видео MP4/MOV до 25 МБ.
- Черновики по каждому чату (localStorage, видно в списке «Черновик: …»).
- Кнопка «вниз» со счётчиком новых, полоса «Новые сообщения», кликабельные ссылки, фото на весь экран с листанием.
- «Печатает…» клиенту (`typing_on`) — не чаще раза в 7 с, только где можно писать.

**Список чатов**
- Закреп (общий, сверху), «пометить непрочитанным» (общий флаг markedUnread), архив (общий; входящее от клиента возвращает чат из архива).
- Метки: справочник ведёт руководство; ставить на чат — кто может отвечать в нём (ведущий + руководство; свободный — все с доступом). Так же — закреп, архив, «непрочитанное».
- Напоминания «вернуться к клиенту»: личные (получает поставивший); в срок — уведомление + пуш, чат поднимается наверх (после закреплённых). Ответ клиенту после срока закрывает напоминание сам.
- Поиск по тексту сообщений и заметок (общий и внутри чата), переход к сообщению с подсветкой.
- Фильтры: метка, «с лидом / без лида», «с напоминанием». Вкладка «Архив».

**Карточка клиента справа** (xl — колонкой, уже — выезжающей панелью): лид с контактами, кто ведёт, метки, напоминания, закреп/архив, фото и файлы чата, заметки.

**Ещё**: @упоминания в заметках (уведомление коллеге), горячие клавиши (Esc, Alt+↑/↓, Ctrl+K, «/», «?»).

## Данные (миграция 1828000000000-DirectChatTools)
- `direct_conversations`: `pinnedAt`, `pinnedById`, `archivedAt`, `archivedById`, `markedUnread`.
- `direct_messages`: `ourReaction`.
- Новые таблицы: `direct_labels`, `direct_conversation_labels`, `direct_templates` (ownerId NULL — общий), `direct_reminders`.
- Типы уведомлений `direct_mention`, `direct_reminder`.

## Проверка
Локальный стенд (TZ=UTC), поддельный Graph API Instagram через `INSTAGRAM_API_URL`, вебхуки с подписью. Сценарии в браузере за МП и админа, компьютер и телефон. Потом commit + push (авто-выкладка), проверка новых маршрутов на проде (401, а не 404).
